# Acãodemia
https://acaodemia.vercel.app

🌐 Projeto de Desenvolvimento Web

Este projeto foi desenvolvido como parte de uma atividade acadêmica na disciplina de desenvolvimento web.

💡 Sobre o projeto

A proposta consistiu na criação de um site para uma empresa fictícia, com o objetivo de simular um cenário real de desenvolvimento e aplicar conceitos aprendidos em aula.

🛠️ Tecnologias utilizadas

HTML

CSS

JavaScript


🚀 Objetivo

Desenvolver um site funcional e bem estruturado, trabalhando aspectos como layout, responsividade e organização de código.

📚 Observação

Este projeto possui fins exclusivamente acadêmicos e não representa uma empresa real.
